# Sourceleaf — Scope

Sourceleaf is a free portfolio demo for asking questions about PDFs and Word documents. Answers link to the passages they use.

## First version

- Visitors can try a sample PDF and DOCX together without signing in.
- Signed-in users can upload multiple text-based PDFs and DOCX files, choose which files to use, and revisit saved chats.
- Users can ask questions, request simpler explanations, and summarize selected files.
- The demo uses free tiers and accepts public or sample material only.

## Outside the first version

Scans, handwriting, OCR, confidential files, shared document libraries, and paid plans.
